# APS360_ASLProject
ASL-to-text: real-time fingerspelling recognition from a webcam, using a custom CNN in PyTorch

## Credits
- Hand detection and landmarks: MediaPipe Hands (Zhang et al., 2020), https://arxiv.org/abs/2006.10214
- `src/landmark_test.py` follows the usage shown in MediaPipe's Hand Landmarker Python guide: https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python
- Dataset: Kaggle ASL Alphabet (Nagaraj, 2018), https://www.kaggle.com/datasets/grassknoted/asl-alphabet
